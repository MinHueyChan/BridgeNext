# BridgeNext mascot design brief

Generated with the built-in OpenAI image-generation tool. New generation from text; no reference image was passed to the model for this sheet.

Production brief: a 3-column × 2-row transparent sprite sheet of one friendly yellow chick, with a separate softly squared head, pear-shaped body, little oval midnight-teal eyes, ivory face patch, swept feather crest, small wedge beak, teardrop wings and fine teal linework. Keep consistent proportions across six outfits: default blue shirt/black trousers, sage accountant vest/calculator, navy analyst vest/chart, lavender admin shirt/folder/mint scarf, teal support shirt/headset, terracotta operations shirt/checklist. No text, logos, panel borders or scenery. Full characters remain inside their equal square cells.

The prior supplied example informed only the broad theme of a yellow chick. The current character changes its silhouette, facial construction, linework and pose.
